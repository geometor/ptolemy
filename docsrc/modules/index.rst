Modules
=======

The ``geometor.ptolemy`` Python package provides 100% exact symbolic ``SymPy`` and ``geometor.model`` constructions, closed-form radical chord tables, sexagesimal base-60 arithmetic, Menelaus spherical transversal verifiers, and stereographic astrolabe projections for Claudius Ptolemy's *Almagest* (Book I) and *Planisphaerium*.

CLI Summary
-----------

.. code-block:: bash

   /home/phi/PROJECTS/geometor/.venv/bin/python -m geometor.ptolemy
